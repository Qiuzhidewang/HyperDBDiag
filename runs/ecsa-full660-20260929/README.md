# ECSA 全部 660 例的固定规则消融

**已完成并复核：718 次新增调用，2,100 个逻辑决策，31 项测试通过。请阅读 [全量 660 例消融结果](全量660例消融结果.md)。**

本轮将 LLM 对照覆盖扩大到现有 v11 的全部 660 例。沿用前一轮已经冻结的保守本地判别规则、训练侧阈值、六折超图模型、证据卡片、提示词和输出约束；没有按本轮输出重新选择参数。论文、图片及历史实验文件保持不变。

## 对照定义

每个案例都有以下三条候选池路径，模型均为官方登录下的 GPT-5.5／xhigh：

1. 不使用本地候选筛选，LLM 在完整四候选池上仲裁。
2. 原本地筛选，LLM 在原一至二候选池上仲裁。
3. 保守本地筛选，LLM 在训练侧校准后的候选池上仲裁。

为隔离候选池的作用，这三条路径都在弃权、非法输出或接口失败时使用相同的超图首选作为回退。另行报告完整组合：第三条路径中的有效选择照常接受，其余情况保留校准后的本地输出。这两个统计口径不混作一种贡献。

不使用 LLM 的超图基线、原规则本地直接读出、校准后的本地直接读出，也在相同 660 例上统一评分。所有方法使用同一套 Exact 与 component micro-F1 计数。

## 复用与重复检查

主实验中完全相同的输入、提示词、输出约束和模型配置共享同一份有效决策。已有决策按请求哈希复用，避免把重复采样波动计作筛选收益。原池的 451 个单候选案例中，唯一候选与共同回退一致；无论有效选择、弃权还是失败，预测均相同，因此解析确定其预测，不冒充新增模型输出。

从保守筛选实际改变候选池的案例中，按冻结的哈希规则每折选择 10 例，共 60 例。对完整池和保守池各新增一次独立调用，共 120 次；此检查与主实验分开，不用第二次较好的答案替换第一次，也不把重复结果算作新增独立案例。

总计 1,980 个主实验方法决策和 120 个重复检查决策。扣除解析确定与已保存结果后，需要 718 次新增调用：598 次补齐主实验，120 次重复检查。并发数为 8，与前轮的 4 不同；不据此比较跨轮延迟。

## 训练和评估范围

仍为六个采集重复折，每折训练 550／测试 110。两项本地阈值来自前轮每折内部五组交叉拟合，当前外层测试标签不参与选择。六折校准值和已拟合模型原样复用。

这扩大的是同一数据集上的 LLM 评估覆盖，消除了只看某个 72 例调用安排的问题；不是新采集的数据集，也不是对未知场景的泛化验证。保守规则来自此前的开发分析，不能称为从未接触过该数据集。另行报告此前检查的 189 例与本轮首次补齐的 471 例，保留这种开发背景。

## 复现

冻结输入已存在，不要重新覆盖。运行或从检查点续跑：

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src ./rca39/bin/python \
  src/ecsa_fullcoverage_experiment.py run
```

完成后分析并复核：

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src ./rca39/bin/python \
  src/analyze_ecsa_fullcoverage.py
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src ./rca39/bin/python \
  src/audit_ecsa_fullcoverage.py
```

`protocol.json` 保存冻结规则和文件指纹；`prepared.json` 保存请求、样本安排和本地预测；`new_model_calls.jsonl` 保存逐次新增调用；全部完成后生成 `decisions.json`、`analysis.json` 与逐例 CSV。输入审计检查共同证据、候选对应、训练测试分离、旧请求一致性和重复样本选择；输出审计重新验证全部决策及回退映射。

报告中的折块自助区间按六个采集重复折重采样；分组样本数不等时使用样本加权的正确数差。只有六个重采样单位，该区间用于探索性稳定性检查，不作为独立场景泛化或强显著性结论。
