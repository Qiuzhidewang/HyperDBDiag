# HyperDBDiag 参数敏感性实验（已完成）

本实验覆盖 α、β、θ、K，使用当前主实验相同的 660 个样本和六折划分，每折 550 个训练样本、110 个测试样本。现有中文稿、英文稿、表格及图片均保持不变。

## 预先固定的设计

- α：0、0.2、0.4、0.6、0.8、1。
- β：0、0.2、0.4、0.5、0.6、0.8、1。
- θ：0.5、0.75、1、1.25、1.5。
- K：1、2、3、4、6、8。
- 加上当前主配置，去除重复的基准点，共 22 组、14,520 次样本评估。
- 每次只改变一个参数；其余参数及本地判别阈值固定为对应外层折的原配置。改变 θ 时重新构建训练超图并训练分支，改变融合权重时复用同一组分支概率。
- LLM 为此前实验使用的 GPT-5.5 / xhigh，通过已登录的官方接口运行。每次推断只收到证据卡片和候选，不包含测试答案、论文或本对话，工具关闭。
- 仅对完全相同的请求复用原始主调用结果（包括原有失败）；新输入重新调用，禁止用重复调用中的更好结果替换。候选数为 1 时，合法选择与回退都会得到同一答案，因此直接计算最终标签，不伪造模型输出或 token 量。

## 当前主配置的来源

α 和 β 由各外层折的训练数据内部进行分组验证，按上游候选集合 Exact 选择；不是根据本轮测试结果调整。α 的候选范围为 0～1、步长 0.1，β 的原搜索范围为 0～0.5、步长 0.1；平分时优先更小的 β、再选更接近 0.5 的 α。非零 β 需带来至少 1 个百分点的训练侧验证增益。

K 在 1～4 中选择满足 95% 训练侧候选覆盖率的最小值，不满足则取 4。六折最终均选择 β=0.5、K=4，α 依次为 0.3、0.4、0.4、0.4、0.5、0.3。θ=1 是固定设置，不能表述为经过相同搜索得到。本次将 β 扩展至 1、K 扩展至 8，用于检查原搜索边界外的表现；不会根据测试曲线回选主配置。

## 当前完成情况

已完成 30 组外层模型训练及全部本地阶段计算，原配置的候选池、局部判别和证据输入均逐例匹配既有主实验。独立审计通过。去重后有 6,369 份推断输入，其中 771 份复用历史主调用、658 份为可直接确定答案的单候选输入，4,940 份需要新 LLM 推断。

全部 4,940 次新增调用已完成，独立审计通过。最终结果和解释见 RESULTS_实验结果.md，审阅图见 parameter_sensitivity_review.pdf。逐次记录见 new_primary_responses.jsonl；local_stage_diagnostics.json 仅是此前保存的本地阶段结果，请勿将其中成绩当作完整 HyperDBDiag 成绩。

本实验检验现有场景上的参数敏感性，不等同于未知场景、数据噪声或分布变化下的鲁棒性测试。单因素曲线也不替代参数交互实验。
