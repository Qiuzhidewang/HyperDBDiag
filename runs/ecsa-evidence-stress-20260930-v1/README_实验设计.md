# ECSA 证据卡扰动与候选范围约束实验

本实验结果需确认后才能写入论文。现有论文、图表、主实验、消融实验及参数敏感性实验均保持不变。

## 冻结设计

从现有 660 个案例中固定抽取 120 个：六折分别选取 8 个单根因与 12 个双根因案例。按固定种子和案例标识的哈希取样，不按历史准确性、置信度或 LLM 状态筛选。样本覆盖全部 18 类根因组合；候选池宽度分别为 2（30 例）、3（8 例）、4（82 例）。候选模型、训练结果和本地筛选已在此前冻结，本次不重新训练、不回选参数。

每个案例构造六组输入：原始输入、相同正证据、清空反证、正反证据错排、仅改变排列顺序、候选外根因诱导。具体转换见 protocol.json，输入见 prepared.json。扰动位于本地筛选之后，不更改候选身份和根因标签；指标轨迹、独立语义观察、训练模式和机制卡均保留。随机错排保留所有正反证据文本的总集合。诱导文本是刻意放入证据正文的对抗内容，不是模型的真实新候选。

共 720 个逻辑评估；7 例“相同正证据”原本已相同，因此与原始输入共用首次响应，共需要 713 份新的模型响应。所有输入先冻结再运行，固定打乱调用顺序。使用与主实验一致的 GPT-5.5 / xhigh、官方登录接口、提示词、schema 和本地校验器。原始对照也重新调用。每份唯一输入只保留一次主调用，失败不以更好的重复调用替换。

## 评价范围

1. 校验前：保存模型可见原始响应，统计不存在的候选编号、竞争候选编号、未知证据引用、解析和校验失败。此响应已经过接口的结构化输出约束，并非完全无约束生成；不读取隐藏推理。
2. 校验后：统计最终输出是否属于输入中的某个完整候选根因集合。弃权、非法输出和传输失败都按当前方法保留本地结果，但分别统计。
3. 诊断效果：相同 120 例上的 Exact、component micro-F1、与新原始对照的逐例改对/改错及预测变化，以及六折结果。
4. 软件检查：每例 7 项人工非法响应或篡改结果检查，共 840 项，与真实 LLM 实验分开，不计作模型调用或真实越界事件。

只报告本次观察到的计数和配对差异，不用单次调用和少量折作强显著性或普遍保证。正确根因原本不在候选池内时，本实验不能恢复它。候选范围内的误诊仍然可能发生；证据编号存在也不等于语义确实支持诊断。这里不评估下游自由文本处理建议的事实性。
